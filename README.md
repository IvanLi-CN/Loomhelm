# Loomhelm

Loomhelm 是面向个人与小型团队的自部署项目管理与 Agent 工作台。

项目将提供 Web/PWA、API 与 MCP 入口，把项目、任务、指定主机上的 Codex 会话、审批、执行结果和产物连接起来。

当前仓库处于工程初始化阶段，尚未提供可运行的产品。

## 产品端术语

项目固定使用三类产品端名称：**服务端**、**客户端**和 **Web App**。其中，客户端可以独立运行，主要负责 Codex 交互以及开发任务辅助；Web App 是浏览器/PWA 用户界面；Codex、MCP 和 Host 属于相关外部系统或协议对象，不另立为产品端。详细定义见 [术语表](GLOSSARY.md)。
