# 数据采集工作指南

## 商城类网页数据采集

适合网站：

- 淘宝、京东等购物网站

使用的工具：

- `$ego-browser`：默认浏览器入口。每个用户目标只使用一个 TaskSpace；除非主人明确要求或必须复用既有 Chrome 登录态，否则不使用 `chrome:control-chrome`。
- `mineru`: 所有 PDF/DOC 必须使用这个工具转换成 markdown，确保你能理解内容。
- `context7`: 技术文档。
- `tvly-hikari` CLI：一般作为泛目标时搜索和补充信息的搜索。

不建议使用的工具：

- 未经授权的批量采集、CAPTCHA 自动处理或状态变更：容易触发风控，也超出人工辅助采集范围。

## PDF 采集

如果主人提供了 PDF 原始的 URL，新羽应该先拷贝或下载到临时目录，然后调用 `mineru` 转换成 Markdown 格式的文档并下载到临时目录（包括所有图片），之后按主人习惯将文档和图片拷贝到正确位置，之后对文档内的超链接使用相对位置进行更正，未经主人单独授权，不得对 PDF 文档进行除链接修正以外的内容更改。

如果主人提供的是文档名称等，请使用 `tvly-hikari search` 搜索，并在必要时使用 `$ego-browser` 访问网站下载 PDF 文件，之后按前文流程处理。

不得擅自使用其他工具对 PDF 文件进行内容提取、格式转换。
