# 术语表

## Multi-task Flow

### Proposal

尚未获得主人实施批准的候选执行计划。Proposal 可以展示依赖、估时和验收设计，但不可调度、不可派发，也不代表已经创建或绑定任何执行资源。

### 执行计划

经过主人明确批准、作为当前调度依据的不可变计划版本。执行计划拥有独立身份、批准记录和授权动作集合；候选 Proposal 与执行计划不得混称。

### 计划完整性

计划在进入批准前必须满足的静态条件集合，包括任务与交付单元、结构化验收合同、依赖语义、估时依据、发布/部署/验证和收口路径。计划完整性通过不等于实施已批准。

### 验收合同

绑定到任务或交付单元的结构化完成约定，包含责任人、可观察条件、证据类型、必需检查和完成状态。验收范围或摘要 digest 只能索引合同，不能替代合同内容。

### 交付单元收口

交付单元在 parent PR 合并后完成合并 SHA 的 CI、适用的发布/部署/验证、已知 follow PR 对账及资源事实确认的终态。`integrated` 只表示贡献已合入，不能单独表示交付单元已收口。

### 交付 Agent 就绪

regular 交付单元在激活前已经绑定独立交付 Agent conversation，并具备后续 parent branch、parent PR 和收口所需的身份。Proposal 阶段可以是未绑定状态，但未绑定不是就绪事实。

### 任务 Agent

拥有一个独立实现任务完整生命周期的唯一执行 Agent，负责任务实现、任务验收、自证、创建并合并自己的 child PR，以及记录合并结果。并非每个任务都需要 Task Agent；main-owned、交付 Agent-owned 和只产出验证证据的任务可以使用其他执行策略。

_Avoid_: 子任务审核人、临时接管 Agent

### 交付 Agent

拥有一个 regular 交付单元的 parent branch 和 parent PR，对 parent PR、合并后的 CI、已声明的合并后交付义务和收口负责。不合并、rebase 或重新审核正常路径中的 child PR；bootstrap 由 Main Agent 直接兼任交付 Agent。

_Avoid_: 交付协调者、child PR 审核人、任务接管者

### 主 Agent

负责整个 run 的依赖图、账本和交付单元调度；只在异常升级或明确授权时参与任务级决策。

_Avoid_: 总审查人

### 任务自证

任务 Agent 针对任务边界、验收条件、测试、PR head/base 和合并结果提交的结构化质量事实。

_Avoid_: 交付协调者审核

### 任务执行策略

每个任务显式声明执行 owner、对话策略和交付方式，三者共同决定任务由谁执行、是否创建新对话以及如何交付结果；任务存在本身不等于必须创建 Task Agent 或 child PR。

### 验证证据

通过结构化报告、日志、CI 结果、演练结果或校验结果证明任务完成的交付方式，不创建 child PR；它不是 Agent 身份，也不是代码质量复核。

### 合并后交付义务

在 delivery unit 的 parent PR 合并后仍必须完成、且已在交付合同中预先声明的 CI、部署、验证、发布或 follow PR 对账事项；不得在合并后临时扩大范围。

### 异常升级

任务 Agent 先完成问题归因；仅当问题确认不由自身 PR 造成，或主人明确要求时，才将诊断、影响和候选处理方案交给主 Agent 进行编排决策。

_Avoid_: 正常 child PR 复核

### 修复贡献任务

为解决外部问题而新建的独立任务，拥有独立 Agent、工作区、验收条件和 PR，不复用原任务的执行身份。

_Avoid_: 原任务代修

### Agent idle

绑定 Codex 对话没有活跃 turn 且最新 turn 已确认终止的运行时观察状态。它只说明对话当前不在工作，不说明停下原因、交接意图、阻塞原因或任务完成意图。

### 版本信封

记录 Skill、账本合同和 Viewer 合同身份的结构化元数据，包括 `skill_id`、`skill_version`、`ledger_schema`、`ledger_contract` 和 `viewer_contract`。版本信封用于判断兼容关系，不替代 source SHA、build ID 或运行时事实。

### 安全迁移

由 Main Agent 执行、具有登记迁移路径、完整备份、expected revision、幂等 request ID 和结果事件的账本迁移。安全迁移只能补充结构或可计算派生状态，不能改变既有责任身份或补造外部事实。

### 对话资源异常

绑定任务对话在归档或观测过程中产生的资源事实，例如归档失败、归档结果未知、连接断开或状态不可用。它与任务业务状态分离。

### 归档闭环

对已完成子任务的绑定对话发起归档、记录明确结果，并在失败或未知时保留可重试或可对账事实的过程。

### Viewer 双读

同一个最新 viewer 根据 run 的格式选择当前 reader 或受支持的历史 reader，并继续以当前格式写入。

### 旧 viewer 只读兜底

最新 reader 无法证明某个 run 可读时，使用已验证的 previous build 生成只读投影；该路径不得写入、改变 owner 或推进 revision。

### 机械迁移

不推断业务事实、可重复执行、可恢复且由备份、内容 digest 和 revision fencing 保护的格式转换。
