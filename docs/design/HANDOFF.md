# Loomhelm UI 布局交接

## 交接范围

本交接包用于在 D、Glass / Layered 语言板确认后继续主要桌面/手机布局与 UX；它约束设计意图、静态源范围和验证入口，不宣称完整产品 UI 已完成。

布局源当前由 `design/layouts.html`、`design/layouts.css`、`design/layouts.js`、`design/layouts-tasks.css` 和 `design/layouts-tasks.js` 组成。本交接沿用现有 [DESIGN.md](DESIGN.md) frontmatter token 和 `docs/design/.impeccable/design.json`，不新增 token 或第二套 layout system。

## 实际静态源范围

`layouts.html` 提供中文评审条、主题选择、场景菜单、桌面侧栏、主内容区、手机导航对话框、创建对话框、弹出菜单和播报区域；它加载 `layouts.css`、`layouts-tasks.css` 和模块入口 `layouts.js`。

`layouts.js` 提供合成项目 Loomhelm、Sidecar Notes、Device Lab，任务/对话/待介入事项数据，以及工作台、全部任务、项目、全部对话和单个对话页面状态。工作台包含待审批、需要输入和结果待核对三类事项，并展示完整命令、目录、影响范围、审批动作和原对话入口。

对话工作区包含主消息区、子代理和工具折叠内容、对话文件、草稿输入、明确发送、任务信息、任务状态选择、绑定任务、历史共享确认和中断请求。绑定面板在确认前显示所选任务 ID/标题和明确的目标项目；没有可绑定任务时选择器禁用，弹出项保留项目标签并由焦点保护安全收束；任务 ID 继承系统字体。手机 CSS 已定义导航抽屉、局部对话/信息面板、窄屏输入和 44px 交互目标；最终捕获和功能检查覆盖这些合成交互的关键路径。

当前脚本的合成场景包括正常、加载中、空状态、加载失败、离线、恢复连接、结果待核对、审批已过期、只读和有可用更新；主题、视图、草稿、阅读位置和演示决策使用本地演示状态。脚本明确不调用产品 API。

任务页面提供搜索、状态筛选和列表/看板/图谱入口；任务模块渲染列表表格、按业务状态分列的看板、带项目节点的关系图谱、父子层级与前置依赖边、图例、缩放和节点列表。它的静态关系数据仍是合成的，跨项目授权和真实关系合同不由该 renderer 证明。

无项目会话上下文和导航使用“对话”；信息面板中的“尚未归属项目”是属性说明，不是导航分组，不构成待解决的标签问题。

## 信息架构交接

全局导航只能有“工作台”和“任务”；其下的“对话”直接列无项目对话，“项目”展开为“项目 → 对话”。没有顶层独立“对话”按钮、主机选择器、主机页面、全局产物页面或任务产物面板。

工作台的“全部对话”是跨项目对话列表和创建路径；创建时可以不选项目或任务。项目内创建预选当前项目，但不改变全局入口的范围语义。

项目的对话叶子同时包含任务主对话和无任务项目对话；任务关联作为元数据可读，但不在项目树中新增任务层。项目工作区的对话面板必须包含该项目全部授权对话。

打开任务进入同一个任务工作区；任务业务状态、执行/审批/连接状态、主会话、子代理活动、共享草稿和对话文件必须保持各自语义，不能汇总成一个“执行中”状态。

## 桌面/手机实现映射

| 结构 | 桌面 | 手机 | 实现检查点 |
| - | - | - | - |
| 上下文导航 | 可折叠的项目/对话树保持在壳层，主区切换不丢上下文 | 抽屉展示同一棵树，关闭后返回原范围和选中项 | 不出现第二套简化层级；面包屑使用真实项目/对话标签 |

| 任务视图 | 列表/看板/图谱使用同一工具栏和任务身份 | 同一控件语义适配窄屏，不以仅桌面显示的筛选/图例替代手机能力 | 全局范围与每个项目范围的视图偏好独立记忆，默认列表 |
| 任务信息 | 对话主区 + 信息 rail | “对话/任务信息”局部面板 | 切换面板不丢草稿、分支展开、阅读位置或待处理状态 |

| 反馈 | 连接、审批、命令和权限反馈靠近相关上下文 | 同样反馈必须可读、可操作、可返回 | 加载、错误、空状态、离线、恢复连接、只读、结果不确定都有下一步语义 |

## 关键流程交接

### 独立对话到任务

创建者可先在无项目状态交流和执行；系统在绑定前必须展示历史消息、执行和文件将按目标项目权限共享的说明，并明确保留草稿私密性。

确认后只允许未绑定会话绑定到没有主会话的任务，并保留原会话、消息、执行、事件、文件引用、草稿和阅读上下文；取消、冲突、无权或失败都回到原状态。

布局不可提供解除、替换或跨项目迁移入口。一个任务与一个会话的绑定均为一期固定关系。

### 审批与执行

工作台和任务工作区都应能进入完整审批请求；用户先看到请求、影响范围、上下文和当前修订，再显式批准/拒绝。过期、已处理或已撤销的审批保留事实但禁用动作。

显示命令已接收、已开始、等待审批、执行结束、连接断开、中断请求中、终止和结果不确定的区别；中断请求中不能用终止样式，结果不确定不能用失败或成功样式替代。

重复提交、ACK 丢失、断线和重启后的 UI 必须引导对账或人工处理；任何重试文案都不能暗示可安全重放。任务完成与执行完成始终分开。

### 多端草稿与更新

桌面和手机可以同时编辑同一个共享草稿，不发生设备接管；冲突按照公共合同的最后修改规则收敛。发送只消耗实际发送内容，并保留发送后产生的新输入。

连接恢复、页面恢复和 PWA 更新都不能发送草稿或排队控制命令；更新提示必须保留任务、会话、面板、展开分支、阅读位置和草稿。

## 证据与当前限制

当前布局源文件是 `design/layouts.html`、`design/layouts.css`、`design/layouts.js`、`design/layouts-tasks.css` 和 `design/layouts-tasks.js`；最终浏览器批次确认五个源文件均加载，默认预览包含“演示数据”及主题/场景控制，`canvas=1` 的纯应用捕获隐藏评审条。

本轮 16 张主要布局捕获覆盖工作台与会话工作区四种主题/设备组合、任务列表/看板/图谱桌面与手机、手机信息面板和导航；随后补充 2 张绑定确认状态，合计 18 张。视口为桌面 1440x1000、手机 393x852，320/768/1024 宽度溢出检查均为 0。聊天交付的四张主要布局快照与源码入口用于页面评审；新布局尚未替换已接受的语言板证据。

25 项合成功能检查通过，覆盖手机 composer 边界、主题/面板/分支/草稿保留、导航后草稿保留、中断请求中且非终态并限定会话、离线时发送/中断禁用、恢复不自动发送、过期审批禁用、审批等待执行事实、记忆视图、图谱缩放与层级/依赖边区分、Escape 恢复焦点、私有历史共享确认、同一对话 ID 绑定和无任务项目创建；一次性 detector 结果为 `[]`，语法检查通过，初始手机 composer/SVG 尺寸已修正且列表已压紧。

独立视觉复核提出的文档同步、项目属性语义、绑定目标可见性和无效字体声明四项修正均已被评为 resolved，修正 verdict 为 `disposition: ship`，未报告修正引入的回归。该判定仅覆盖这四项修正；以上均为合成演示证据，完整布局的主人确认仍待完成，不能据此标记完整 UI 已批准。
