# ADR 0020：以运行时观察表达 Agent 空闲，并独立记录对话归档

## Status

Accepted

## Context

multi-task-flow 需要发现子任务 Agent 对话停止工作的异常，但 Codex 最新 turn 已结束本身不能说明子任务为什么停止，也不能推断它在等待主对话、请求交接或已经完成。对话归档失败同样属于资源问题，不应改变任务已经确认的业务终态。

## Decision

新增 `agent_idle` 运行时观察状态，表示绑定对话没有活跃 turn 且最新 turn 已确认终止。该状态不修改既有 Task 业务状态，不推导交接或完成意图；连接未知与恢复中的状态继续使用独立资源异常语义。

任务终态和 conversation resource 的归档状态分离。子任务进入明确终态后及时尝试归档；成功标记资源 `closed`，失败或未知保留可重试/可对账的资源状态。dashboard 必须展示归档异常并提供只重试归档的“重新归档”操作。

## Consequences

观察器可以发现“对话不工作”的异常，同时避免把停顿原因写死在状态机中。实现需要保存 turn 终止证据、归档 operation identity 和资源错误详情；UI 需要增加 idle 与归档异常图标及详情。任务执行恢复仍由用户或既有流程负责。
