# ADR 0019：迁入执行支持与 POSIX 安全适配

## 状态

Accepted

## 背景

完整迁入的脚本依赖包外共享模块及 Bun FFI。仅复制 Skill 入口会产生缺失引用；用另一套任务图重写则丢失原有运行合同。Node.js 文件系统 API 没有完整暴露源代码使用的目录描述符相对操作、flock 和原子不覆盖重命名。

## 决策

源包保留在根 `skills/`，共享支持保留在根 `bin/`；生产构建携带资源而不依赖全局来源目录。只迁入锁定提交中跟踪的文件。外部安装的 Skills 仍由宿主明确提供，缺失时返回适用阻塞。

使用最小稳定 Node-API 原生适配承接必要 POSIX 操作，保留 TypeScript 中的业务、协议和协调语义。Node.js 与 Bun 使用相同适配，不增加 Python 安全辅助进程。生产路径使用 Node 兼容接口，原构建及测试专用 Bun 能力可保留。

## 取舍

直接保留 Bun FFI 最省迁移工作，但违反生产双运行时合同；路径预检查和另造锁不能保持竞态安全与旧进程互斥。Python 标准库可以提供相关系统调用支持，但新增辅助进程生命周期和运行依赖，因此不采用。原生适配增加按平台构建与验证成本，换取明确且共用的系统调用边界。

不改变旧账本或用户现有服务的归属；迁移程序本身不授权修改全局配置、其他项目或真实旧运行。
